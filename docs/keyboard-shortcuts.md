# Keyboard Shortcuts

The full set of built-in shortcuts. All shortcuts are also visible in the command palette (++cmd+k++) next to each action, so this page is for reference — you never need to memorize it.

## Panes

| Action | Shortcut |
|---|---|
| Split horizontal | ++cmd+d++ |
| Split vertical | ++cmd+shift+d++ |
| Close pane | ++cmd+w++ |
| Toggle stack | ++cmd+shift+s++ |
| Focus left | ++alt+h++ |
| Focus down | ++alt+j++ |
| Focus up | ++alt+k++ |
| Focus right | ++alt+l++ |

## Sessions and windows

| Action | Shortcut |
|---|---|
| New session | ++cmd+n++ |
| Settings | ++cmd+","++ |

## Navigation

| Action | Shortcut |
|---|---|
| Command palette | ++cmd+k++ |
| Toggle notes | ++cmd+b++ |
