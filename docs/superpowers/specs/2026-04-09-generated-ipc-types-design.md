# Generated IPC Types Design

## Problem

Rust and TypeScript type definitions are hand-maintained separately, leading to drift risk. Several event payloads use ad-hoc `json!()` calls with no Rust struct definition.

## Solution

Use `specta` + `tauri-specta` to generate TypeScript types from Rust structs. Replace hand-maintained TS type definitions with generated bindings. Define proper Rust structs for event payloads.

## Library Choice

- `specta = "2.0.0-rc.24"` — derive macro for type export
- `tauri-specta = "2.0.0-rc.24"` — Tauri integration, generates typed invoke wrappers
- `specta-typescript = "0.0.9"` — TypeScript code generation

## Types to Annotate with `#[derive(specta::Type)]`

**Command return/param types (already exist in Rust):**
- `Session` (session.rs)
- `Project` (projects.rs)
- `RouxSettings` (settings.rs)
- `Worktree` (worktree.rs)
- `ClaudeSession` (services/sessions.rs)
- `DocFile` (services/docs.rs)
- `SetupStatus` (commands/setup.rs)
- `Watch`, `WatchKind`, `WatchMode`, `WatchScope`, `WatchResult`, `WatchOutcome`, `RuntimeState`, `NotifyConfig`, `GithubJob`, `PrReview`, `PrCheckRun`, `CreateWatchConfig` (watches.rs)
- `TaskDefinition`, `TaskGroup` (tasks.rs)

**Event payloads (already exist in Rust):**
- `WatchUpdateEvent` (watches.rs)
- `StatusUpdate` (status_watcher.rs)

**Event payloads (new Rust structs needed):**
- `SessionExitPayload` — emitted from pty.rs on PTY exit
- `RouxCommand` — emitted from socket.rs handlers
- `SessionStatusPayload` — emitted from status_watcher.rs (check if StatusUpdate already covers this)

## String Enum Conversions

Replace loose `String` fields with proper enums where the frontend restricts values:
- `Session.status` → `SessionStatus` enum: Idle, Thinking, Generating, Error, Disconnected, Attention
- `RouxSettings.cursor_style` → `CursorStyle` enum: Block, Underline, Bar
- `RouxSettings.tab_position` → `TabPosition` enum: Left, Right
- `RouxSettings.group_by` → `GroupBy` enum: Repo, Project
- `TaskDefinition.keep_open` → `KeepOpen` enum: Always, OnError, Never

## Generated Output

`src/lib/bindings.ts` — all TypeScript types + typed command functions. Generated by a build script or `task gen-types` command.

## Frontend Changes

- Delete hand-maintained types from `src/lib/types.ts`, `src/lib/types/watches.ts`, `src/lib/types/tasks.ts`
- Import from `src/lib/bindings.ts` instead
- Keep frontend-only types (`TaskRun`, `PermissionInfo`) in their current files
- Update `src/lib/tauri.ts` to use generated types and invoke wrappers

## Workflow

`task gen-types` runs a Rust binary that exports types to `src/lib/bindings.ts`. Developers run this after changing IPC-facing structs.
